# Investigation

Identify expected versus observed behavior and the triggering input. Read errors and the relevant execution path; reproduce with an allowed focused check where practical. Distinguish reproduction from source inspection.

Separate facts from hypotheses. Choose a check that distinguishes plausible causes before patching; expand into callers or data only for that question. Report inaccessible evidence and missing product decisions rather than inventing them.

Return the supported cause, file/symbol, smallest correction and recurrence check. An authorized fix may proceed; investigation-only stops at findings. If attempts yield no new evidence, use [recovery](recovery.md).

# Context on demand

Use this reference for missing context, compaction or drift; use [investigation](investigation.md) when behavior itself is unclear. Reuse unchanged guidance and reread only necessary parts. Paths are references, not evidence that contents were inspected.

Keep a short working account of the relevant execution path, verified findings, assumptions, binding decisions and next unresolved question. Include source locations or check results that support consequential claims. Maintain it in the conversation as needed; no custom retrieval system or persistent task-state file is required. After changes, revisit assumptions and evidence affected by the new state instead of replaying all earlier exploration.

A worker reads within its assignment. For missing authority, inaccessible artifacts or unclear interfaces, return the specific question, minimal target and consequence. The coordinator supplies a narrow answer, not the conversation history. Carry binding answers into later assignments and final review.

Do not trim essential criteria or decisions. Keep long logs in authorized artifacts and return relevant excerpts/references. For continuation use [handover](../../ai-handover/SKILL.md), inspect current code/Git state and worker liveness, and recheck affected results.

Count coordinator and worker usage, including retries/reviews, when measuring cost. Unavailable usage stays unknown; shorter instructions alone do not establish savings.

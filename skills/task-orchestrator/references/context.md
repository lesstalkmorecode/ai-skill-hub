# Missing context

Use Codex's native context management and compaction. If essential task context is missing,
inspect current source and applicable guidance, then ask only for the unresolved decision or fact.
Use [investigation](investigation.md) when the behavior itself is unclear.

## Session transfer

Only when a session transfer is actually needed, provide a short note in chat: outcome and
boundaries, repo/worktree, binding decisions, unfinished work, actual checks and the next step.
Include active worker ownership only when relevant. Exclude secrets; save a file or message
another session only when requested. The receiver checks current code/Git state and any active
workers before acting; historical notes are context, not proof of current verification or authority.

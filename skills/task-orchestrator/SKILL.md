# Task orchestrator

Resolve links here; pack root: two levels above unless supplied. Report inaccessible guidance.

Honor scope and existing edits. Investigation, proposals and reviews do not authorize implementation. No routine menus; ask about consequential unknowns. Delegate only when useful and permitted; small tasks stay single-agent.

Before editing, locate the affected path, callers, tests and repository conventions. Implement understood local changes directly; use the references below when uncertainty or consequence warrants more structure. Planning and delegation are optional; reassess when evidence changes scope or risk.

Read target instructions/source and use [Learning](references/learning.md) only to retrieve applicable saved guidance at task start. Load references only for the matching trigger; Delivery owns substantial-work criteria and checks:

## Final verification gate

Inspect final changes against criteria; report actual checks, gaps and consequential decisions.
Self-review is not independent review. Essential gaps prevent verified completion.

## Review before learning

Present the verified result and explicitly ask for final review. Complete requested revisions,
rerun relevant checks and ask again. Only explicit final acceptance permits loading
[lesson proposal and storage](references/learning-capture.md); silence, passing checks and earlier
code approval do not count. Saving a proposed lesson requires separate approval.

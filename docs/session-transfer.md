# Optional session transfer

Use Codex's native context management and compaction. Only for a needed cross-session transfer,
provide a short note in chat: goal/boundaries, repo/worktree and current state, binding decisions,
completed/unfinished work, actual checks and next action. Include active ownership when relevant.
Exclude secrets. Write a file or message another session only when requested.

The receiver checks current source/Git state and any active writers before acting. Historical notes
are context, not proof of current verification, approval or permission. No separate skill or
persistent task database is needed.

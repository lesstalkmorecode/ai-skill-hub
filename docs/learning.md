# Optional lessons

Learning is outside the coding loop. Do not scan lessons, propose memory updates or require user
acceptance as part of normal completion. Read only applicable guidance explicitly supplied by
the user or project; current instructions and observed code take precedence over stale lessons.

When the user requests a reusable lesson, keep it to a rule, supporting evidence, scope and limits.
Persistent writes require authorization for the concrete content and destination; task completion
alone grants none. Use the requested local path and preserve unrelated entries. Do not invent a
storage registry, project-ID scheme, source-checkout search or automatic migration. If a path is
missing, present the lesson in chat and resolve the destination before saving.

Keep private knowledge, secrets, transcripts and machine paths out of shared guidance. Local
`learning/` remains gitignored and excluded from distributions. Do not save in an installed plugin
cache or change shared skills unless the user explicitly requests that change.
